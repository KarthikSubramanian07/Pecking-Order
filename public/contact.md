# Talk to the hen.

Pecking Order is a small open-source project with no support desk and no mailing list. Conversations happen in the open on GitHub, so the answer is there for the next person with the same question.

- [Report a bug](https://github.com/KarthikSubramanian07/Pecking-Order/issues/new?template=bug_report.yml): say what you did, what you expected and what happened instead. Your browser and device help a lot.
- [Suggest a feature](https://github.com/KarthikSubramanian07/Pecking-Order/issues/new?template=feature_request.yml): describe the problem you are trying to solve before the solution you have in mind.
- [Request a category pack](https://github.com/KarthikSubramanian07/Pecking-Order/issues/new?template=pack_request.yml): name the category and a few items. Even better, add the pack yourself: it is one JSON file in the repository.
- [Ask a question or share a board](https://github.com/KarthikSubramanian07/Pecking-Order/discussions): GitHub Discussions is the place for questions, show-and-tell and general chat.
- [Report a security issue](https://github.com/KarthikSubramanian07/Pecking-Order/security/advisories/new): please do not open a public issue. Report it privately through GitHub Security Advisories instead.
- [Buy me a coffee](https://buymeacoffee.com/winnerkarthik): Pecking Order is free and has no ads. Tips keep it that way.

This is maintained in spare time, so replies can take a few days. Thank you for your patience.
